# 辅助驾驶验证应用 - 需求文档（PRD）

## 1. 项目概述

### 1.1 项目背景
基于2026年新车险专项汇报中的辅助驾驶保险需求，开发一款辅助驾驶验证应用，用于模拟和验证辅助驾驶功能，确保智驾事故判定的准确性。

### 1.2 项目目标
- 模拟特斯拉和小鹏的辅助驾驶验证功能
- 实现智驾状态监控和驾驶行为分析
- 提供事故检测和报警功能
- 建立驾驶评分系统

### 1.3 产品定位
面向车主的辅助驾驶验证工具，帮助用户：
- 了解自己的智驾使用情况
- 验证辅助驾驶功能是否正常工作
- 获得驾驶行为评分和改进建议
- 模拟智驾事故判定流程

---

## 2. 功能需求

### 2.1 智驾状态监控

#### 2.1.1 功能描述
实时监控车辆智驾状态，包括：
- 当前智驾模式（NOA/LCC/泊车等）
- 智驾开启/关闭状态
- 车道保持状态
- 自动跟车距离
- 限速识别状态

#### 2.1.2 界面展示
- 实时仪表盘显示
- 智驾状态指示灯
- 速度和时间信息

### 2.2 驾驶行为分析

#### 2.2.1 功能描述
记录和分析驾驶过程中的行为：
- 急加速/急刹车次数
- 变道频率
- 车道保持时间
- 智驾接管次数
- 超速情况

#### 2.2.2 数据指标
| 指标 | 说明 |
|------|------|
| 安全评分 | 0-100分，根据驾驶行为综合计算 |
| 智驾覆盖率 | 智驾行驶里程/总行驶里程 |
| 接管频率 | 人工接管次数/智驾时长 |
| 异常事件 | 急加速、急刹车、偏离车道等 |

### 2.3 事故检测与判定

#### 2.3.1 功能描述
模拟智驾事故检测和判定流程：
- 事故自动检测（T0时刻识别）
- 智驾状态回溯
- 判定结果输出
- 理赔流程模拟

#### 2.3.2 判定逻辑
```
IF 事故发生时智驾开启 AND 智驾功能正常 THEN
  判定为智驾事故，豁免出险次数
ELSE
  判定为普通事故，正常计次
```

#### 2.3.3 判定时效
- 自动判定：30分钟内
- 人工复核：支持

### 2.4 驾驶报告生成

#### 2.4.1 功能描述
生成详细的驾驶报告：
- 日/周/月报
- 驾驶评分趋势
- 智驾使用统计
- 改进建议

#### 2.4.2 报告内容
1. **总体评分**：安全驾驶评分
2. **智驾数据**：智驾时长、里程、接管次数
3. **异常事件**：各类异常事件统计
4. **对比分析**：与历史数据对比
5. **改进建议**：基于行为分析的优化建议

### 2.5 模拟场景测试

#### 2.5.1 功能描述
提供多种模拟测试场景：
- 高速NOA测试
- 城市LCC测试
- 泊车辅助测试
- 应急情况处理测试

#### 2.5.2 测试项目
| 场景 | 测试内容 | 预期结果 |
|------|----------|----------|
| 高速NOA | 自动变道、自动超车 | 正常启用 |
| 城市LCC | 车道保持、自动跟车 | 正常启用 |
| 泊车辅助 | 自动泊入、自动泊出 | 正常启用 |
| 紧急制动 | 前车急停检测 | 及时触发 |

## 3. 用户交互需求

### 3.1 用户角色
- **普通用户**：使用验证功能，查看报告
- **管理员**：管理数据，审核异常

### 3.2 核心流程

#### 3.2.1 主流程
```
用户打开应用 → 选择功能模块 → 查看数据/执行测试 → 获取结果/报告
```

#### 3.2.2 事故判定流程
```
事故发生 → 自动检测 → 获取智驾状态 → 判定分析 → 输出结果 → 理赔模拟
```

### 3.3 界面布局
- **首页**：仪表盘总览
- **智驾监控**：实时状态展示
- **驾驶分析**：行为数据图表
- **事故判定**：判定工具
- **我的报告**：历史报告列表

---

## 4. 非功能需求

### 4.1 性能要求
- 页面加载时间 < 2秒
- 数据更新频率：1秒
- 报告生成时间 < 5秒

### 4.2 兼容性要求
- 支持主流浏览器（Chrome/Safari/Edge）
- 响应式布局，支持手机/平板/PC

### 4.3 安全要求
- 数据本地存储，不上传服务器
- 用户隐私保护
