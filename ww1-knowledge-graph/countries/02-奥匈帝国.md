# 奥匈帝国（Österreich-Ungarn）

## 概述

奥匈帝国是第一次世界大战中同盟国阵营的重要成员，也是战争的直接导火索。这个由哈布斯堡王朝统治的庞大多民族帝国，包含了十几个不同民族和语言群体，在民族主义浪潮的冲击下早已摇摇欲坠。萨拉热窝事件中奥匈帝国皇储弗朗茨·斐迪南大公的遇刺，成为引爆一战的直接原因。

奥匈帝国的二元体制——奥地利帝国内莱塔尼亚和匈牙利王国——是1867年妥协的产物。这种政治安排虽然暂时缓解了匈牙利人的不满，却忽略了帝国境内其他民族——捷克人、波兰人、克罗地亚人、塞尔维亚人、罗马尼亚人等——的政治诉求，成为帝国内部不稳定的根源。

作为德国的盟友，奥匈帝国在一战中表现疲弱，其军事力量与帝国的庞大领土和人口极不相称。战争不仅没有挽救帝国，反而加速了它的崩溃。1918年战争结束时，这个延续了数百年的帝国彻底解体，分裂为多个民族国家。

## 核心内容

### 政治体制

奥匈帝国的独特之处在于其二元君主制：

- **皇帝兼国王**：弗朗茨·约瑟夫一世（1848-1916年在位），同时为奥地利皇帝和匈牙利国王
- **共同事务**：外交、军事和财政由共同政府管理
- **奥地利部分**（内莱塔尼亚）：设有帝国议会（Reichsrat）
- **匈牙利部分**（外莱塔尼亚）：设有匈牙利议会
- **1867年妥协**（Ausgleich）：确立二元体制的基本框架

帝国议会中的民族冲突使正常立法极为困难，捷克人和德意志人之间的对立尤为尖锐。

### 民族构成

奥匈帝国是欧洲最多民族的国家，主要民族包括：

| 民族 | 人口（约） | 主要分布地区 |
|------|-----------|------------|
| 德意志人 | 1200万 | 奥地利、波希米亚 |
| 马扎尔人 | 1000万 | 匈牙利 |
| 捷克人 | 650万 | 波希米亚、摩拉维亚 |
| 波兰人 | 500万 | 加利西亚 |
| 乌克兰人 | 400万 | 加利西亚东部 |
| 罗马尼亚人 | 330万 | 特兰西瓦尼亚 |
| 克罗地亚人 | 280万 | 克罗地亚、达尔马提亚 |
| 斯洛伐克人 | 200万 | 匈牙利北部 |
| 塞尔维亚人 | 190万 | 波斯尼亚、伏伊伏丁那 |
| 斯洛文尼亚人 | 130万 | 卡尼奥拉 |

这种极端的民族多样性使帝国内部治理极为困难。

### 经济状况

奥匈帝国的经济发展极不均衡：

- **工业化程度**：波希米亚和奥地利西部高度工业化，匈牙利和东部地区以农业为主
- **铁路网络**：维也纳-布达佩斯-的里雅斯特轴心是经济命脉
- **农业**：匈牙利平原是帝国的粮仓
- **军工产业**：斯柯达兵工厂是欧洲最重要的军火制造商之一

### 军事力量

奥匈帝国军队面临独特的挑战：

- **语言问题**：军队使用多达11种语言，命令传达困难
- **民族忠诚**：不同民族的部队对帝国的忠诚度差异很大
- **指挥体系**：总参谋长康拉德·冯·赫岑多夫虽然有才能，但协调能力不足
- **训练水平**：与德军相比明显落后

## 一战中的角色

### 战争导火索

1914年6月28日，奥匈帝国皇储弗朗茨·斐迪南大公在萨拉热窝被塞尔维亚民族主义者加夫里洛·普林西普刺杀。这一事件直接引发了七月危机，最终导致大战爆发。

### 军事行动

- **塞尔维亚战线**：三次入侵塞尔维亚，前两次均遭失败
- **加利西亚战线**：1914年遭受俄军重创，丧失大片领土
- **戈尔利采-塔尔努夫攻势**：1915年在德军帮助下取得突破
- **布鲁西洛夫攻势**：1916年俄军攻势几乎摧毁奥匈军队
- **意大利战线**：在伊松佐河进行了十二次战役
- **卡波雷托战役**：1917年德奥联军取得大胜

### 帝国困境

战争暴露了帝国的深层弱点：

- 军队伤亡惨重，战前训练有素的职业军官团几乎消耗殆尽
- 后勤补给困难，粮食短缺导致民众生活水平急剧下降
- 民族矛盾激化，捷克、南斯拉夫等民族的独立运动日益高涨
- 1916年弗朗茨·约瑟夫一世去世，新皇帝卡尔一世无力挽救局势

### 帝国崩溃

1918年秋，奥匈帝国在军事和政治上同时崩溃。各民族纷纷宣布独立：捷克斯洛伐克（10月28日）、南斯拉夫（10月29日）、匈牙利（10月31日）、奥地利（11月12日）。11月3日，奥匈帝国签署停战协定，帝国正式终结。

## 历史影响

### 对中欧的影响

- 帝国解体后诞生了奥地利、匈牙利、捷克斯洛伐克、南斯拉夫等新国家
- 大量德意志人和匈牙利人成为少数民族，埋下民族冲突的种子
- 中欧的政治格局被彻底重组
- 《圣日耳曼条约》和《特里亚农条约》确认了帝国的解体

### 对世界的影响

- 奥匈帝国的崩溃是20世纪民族自决原则的重要实践
- 多民族帝国的解体模式影响了此后苏联、南斯拉夫等国家的命运
- 哈布斯堡王朝的终结标志着欧洲旧秩序的彻底瓦解
- 巴尔干地区的民族问题在帝国崩溃后并未得到解决，反而更加复杂
